# Заявки с сайта в MAX

Сайт отправляет заявку (квиз или обратный звонок) в небольшую серверную функцию, а та пишет сообщение в MAX от имени вашего бота. Токен бота хранится только в функции: на GitHub Pages его класть нельзя, иначе любой сможет писать от имени бота.

```
сайт  →  функция (Яндекс Облако)  →  бот MAX  →  вам в MAX
```

Функция размещается в Яндекс Облаке, поэтому имена и телефоны клиентов не уходят за пределы России (152-ФЗ). Бесплатного объёма вызовов с запасом хватает для лендинга.

## 1. Создайте бота в MAX

1. Зайдите на [business.max.ru/self](https://business.max.ru/self) и создайте профиль организации. Подойдут ООО, ИП или самозанятый, профиль нужно верифицировать.
2. В разделе «Чат-боты» нажмите «Создать», заполните название, описание и логотип 500×500.
3. Дождитесь модерации: до 48 часов по рабочим дням.
4. После публикации откройте бота, затем «⋮» → «Настройки» и скопируйте токен.

## 2. Узнайте свой user_id

Ссылка на профиль вида `max.ru/u/...` не подходит: API нужен числовой ID.

1. Найдите своего бота в MAX и напишите ему любое сообщение.
2. Выполните в этой папке:

```bash
MAX_TOKEN=ваш_токен node get-user-id.mjs
```

Скрипт выведет `user_id` всех, кто писал боту. Если заявки нужны в группе, добавьте бота в групповой чат и используйте `MAX_CHAT_ID` вместо `MAX_USER_ID`.

## 3. Разверните функцию в Яндекс Облаке

1. В [консоли Яндекс Облака](https://console.yandex.cloud) откройте Cloud Functions и создайте функцию.
2. Среда выполнения: Node.js 22. Загрузите `index.js` и `package.json` из этой папки.
3. Точка входа: `index.handler`, таймаут: 10 секунд.
4. Переменные окружения:

| Имя | Значение |
| --- | --- |
| `MAX_TOKEN` | токен бота |
| `MAX_USER_ID` | ваш user_id из шага 2 |
| `ALLOWED_ORIGIN` | `https://ghost1443.github.io` (через запятую можно добавить свой домен) |

5. Включите «Публичная функция» и скопируйте адрес вида `https://functions.yandexcloud.net/d4e...`.

## 4. Подключите сайт

В `index.html` впишите адрес функции:

```html
<meta name="lead-endpoint" content="https://functions.yandexcloud.net/d4e...">
```

Опубликуйте изменения. Отправьте тестовую заявку с сайта: сообщение должно прийти в MAX в течение пары секунд.

## Что проверяет функция

- Принимает запросы только с адресов из `ALLOWED_ORIGIN`.
- Проверяет имя и телефон, обрезает длинные поля, отбрасывает заявки ботов (скрытое поле).
- Если MAX не принял сообщение, сайт показывает посетителю ошибку и предлагает позвонить, а функция пишет причину в логи.
- Адрес API по умолчанию `https://platform-api.max.ru`. Новый адрес `platform-api2.max.ru` требует сертификата Минцифры; его можно задать в `MAX_API`, если среда доверяет этому сертификату.
